# 한국어 문장 규칙 (korean-writing)

> 보고서 한국어 문장이 어색하게 나오는 문제를 막기 위해 국내 라이팅 가이드와 연구를 조사해 정리한 규칙이다.
> 적용: 보고서에 나가는 모든 문장 (s4_insights.md, s5_report.md, html, docx). 코드, 설정 파일, 하네스 내부 문서는 대상이 아니다.
> 함께 쓰는 것: `harness/judge/check_korean.py`(기계 검사), `docs/writing-examples.md`(어색한 문장과 고친 문장 쌍).

## 1. 기본 원칙

- 가운뎃점(·), em dash(—), en dash(–)를 쓰지 않는다. 나열은 쉼표나 "와/과"로, 범위는 물결표(~)로. (korean-writing-style 스킬의 규칙에서 가져왔다. 영문과 숫자 범위의 en dash만 예외)
- 아래 규칙은 형태소 분석 검사(3번)로 기계가 먼저 후보를 찾는다.
- 사람이 어색하다고 짚은 문장은 `docs/writing-examples.md`에 쌓고, 글을 쓸 때마다 먼저 읽는다.

## 2. 규칙

| 묶음 | 규칙 | 근거 |
| --- | --- | --- |
| 한 문장 한 메시지 | 대조할 사실이 둘이면 두 문장으로 나눈다. 강도가 다른 사실(있음, 일부, 없음)을 한 문장에 뭉치지 않는다 | 토스 라이팅 원칙, 카카오 10계명 |
| 은/는 | 한 문장에 보조사 은/는은 두 번까지. 나머지는 이/가, 을/를로 바꾼다 | 조사 결과 종합 |
| 관형절 | 한 명사 앞에 서술어를 세 개 넘게 쌓지 않는다. 길면 뒤로 빼서 서술어로 만든다 | 카카오 10계명(수식어는 피수식어 바로 앞) |
| 주어와 서술어 | 주어와 서술어만 뽑아 읽어도 말이 되게. 막연한 주어("주요 서비스")보다 행위자("사용자", 서비스 이름)를 세운다 | 카카오 10계명, 김정선 |
| 번역투 | "~에 대해/대한", "~를 통해", "~에 있어서", "가지고 있다", "되어지다"는 즉시 고친다. "~에 의해", "~라는 점에서", "~할 수 있을 것으로 보인다"는 한 문서에 두 번까지 | korean-writing-style, 이오덕, 김정선 |
| 흐린 말 | "부분적으로", "전반적으로", "상대적으로" 대신 무엇이 얼마나인지 쓴다 ("일부에만 있다", "동행자 필터만 있다") | 카카오 10계명(막연한 말 대신 수치) |
| 명사화 | "~의 부재", "~ 제공"은 "없다", "준다"로. 표 셀과 짧은 개조식은 예외 | 김정선, 국립국어원 쉬운 공공언어 |
| -적, 의, 것 | "-적", "의" 연쇄, "것이다" 종결을 줄인다 | 김정선, 이오덕 |
| AI 문체 | "A가 아니라 B" 대구, 문장 첫머리 "또한, 따라서, 즉"의 반복, 연결어미 뒤 습관적 쉼표, 볼드와 줄표 장식을 줄인다 | KatFishNet(ACL 2025), 페블러스 2026-08, im-not-ai |
| 생활어 | 추상 명사("목적과 동행자")보다 사용자가 쓰는 말("누구와 무엇을 하러")로 | 토스 Universal words |

## 3. 기계 검사 (`python harness/judge/check_korean.py <md>`)

기준 수치는 `harness/rules.yaml` korean. Kiwi 형태소 분석기로 보조사와 관형형 어미를 구분한다.

- 실패: 금지 문장부호, 거친 표현, S1 번역투, S2 패턴이 한 문서에 3회 이상
- 경고: 은/는 3개 이상, 명사 앞 관형절 서술어 3개 이상, 흐린 말, 칸별 길이 초과, 연결어미 뒤 쉼표 10% 초과
- 검사는 후보를 찾을 뿐이다. 판정은 다시 읽어서 내린다. 집단 통계(AI가 쉼표를 더 쓴다 등)를 문장 하나에 그대로 적용하지 않는다.

## 4. 자가 교정 절차 (초안을 쓴 뒤)

1. 문장마다 "그래서 무엇이 어떻다는 것인가"를 짧게 말해 본다. 두 개면 나눈다.
2. 주어와 서술어만 뽑아 읽는다. 말이 안 되면 행위자를 세운다.
3. 명사 앞 꾸밈이 길면 뒤로 빼서 서술어로 만든다.
4. "~의 부재", "~에 대한 지원"을 동사로 푼다.
5. check_korean.py를 돌린다. 실패는 모두, 경고는 바꿀 말이 있을 때 고친다. 원문 대비 30% 넘게 바꾸지 않는다.
6. 지워도 뜻이 같은 말("다양한", "매우", "앞으로")을 지운다.
7. 소리 내어 읽는다. 숨이 차거나 은/는이 겹쳐 들리면 고친다.
8. 고친 문장이 사실의 강도(있음, 일부, 없음)를 바꾸지 않았는지 원래 사실과 대조한다.
9. docs/writing-examples.md의 실패 유형과 겹치는지 확인한다.
